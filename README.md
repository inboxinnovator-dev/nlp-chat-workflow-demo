# NLP Chat Workflow Demo

## Description
This project demonstrates a simple NLP-based chatbot workflow using Python. It shows how user input is processed and mapped to predefined intents.

## Problem
Understanding NLP workflows can be difficult without a simple example.

## Solution
A rule-based chatbot that performs:
- Text preprocessing
- Intent classification
- Response generation

## Technologies Used
- Python
- JSON
- NLP preprocessing concepts

## How It Works
1. User enters a message
2. Text is cleaned and tokenized
3. Intent is identified using keyword matching
4. Predefined response is returned
